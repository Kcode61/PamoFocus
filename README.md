#  Pamofocus

Pamofocus é um aplicativo de produtividade inspirado na técnica **Pomodoro**, criado para ajudar você a manter o foco, organizar tarefas e equilibrar períodos de trabalho com pausas estratégicas.

O projeto foi desenvolvido utilizando tecnologias modernas do ecossistema React, proporcionando uma interface rápida, responsiva e altamente personalizável.

# 🧠 Técnica Pomodoro

A técnica Pomodoro é um método de produtividade que divide o trabalho em ciclos:

1. **25 minutos de foco**
2. **5 minutos de pausa**


Isso ajuda a:

- melhorar a concentração
- evitar fadiga mental
- manter consistência no trabalho

# 🛠️ Tecnologias utilizadas

Este projeto foi construído utilizando:

- **Next.js**
- **React**
- **TypeScript**
- **Zustand** (gerenciamento de estado)
- **TailwindCSS** (estilização)
- **Lucide Icons**
- **next-themes** (dark mode)

---

# Personalização de temas

O Pamofocus permite escolher entre múltiplos temas de cores, que alteram:

- cor do modo foco
- cor da pausa curta
- cor da pausa longa

Esses temas são gerenciados com Zustand para manter o estado global.
